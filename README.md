## 🌟 Overview

This portfolio is more than just a personal website—it's an immersive digital experience designed to showcase my journey, skills, projects, and passion for Artificial Intelligence and Software Engineering.

The website features a cinematic 3D environment, a custom AI assistant, smooth animations, and an interactive user experience that reflects my interests in modern web development and intelligent systems.
